Why pinned to r128
------------------
Matches the version the legacy CDN-loaded topology visualizer was
already using (gcore-mu/wp-hooks.php pre-vendoring referenced
cdnjs r128). API drift to newer revisions (r150+ removed
WebGLRenderer.gammaInput etc.) would break the existing
THREE.SphereGeometry / MeshPhongMaterial / WebGLRenderer code.

Upgrade path
------------
Bumping to r160+ requires switching to the modular ESM build and
adapting the Topology 3D renderer. Out of scope for now; revisit post-launch.
